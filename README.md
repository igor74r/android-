# Помощник Апокалипсиса — Android prototype 0.3.0

Отдельный Android-проект для безопасного сопровождения игры «Апокалипсис: Убийца Богов».

## Текущий статус

Это прототип интерфейса и локальной логики безопасности, а не готовый игровой бот.

- Kotlin + Jetpack Compose; minSdk 26, targetSdk 35.
- Fail-closed: неизвестная или платная стоимость блокирует действие.
- Планировщик показывает только вручную отмеченные как бесплатные и готовые активности.
- Есть проверка уменьшения известных игровых балансов.
- Есть unit-тесты базовых правил.

## Важно: что пока НЕ реализовано

Приложение пока не считывает экран игры, не нажимает игровые кнопки, не запускает Blitz и не работает в фоне 24/7. Никакие игровые действия автоматически не выполняются. Ручная отметка «бесплатно» — это пользовательская пометка, а не подтверждение фактической цены.

## Жёсткие ограничения расходов

Приложение не должно тратить алмазы, золото, валюты, ресурсы, билеты или другие игровые ценности. Неизвестная цена, неоднозначная кнопка или неожиданный расход должны приводить к блокировке и остановке. Не автоматизировать покупки, платные ускорения, платные попытки, платные призывы и обмены.

## Сборка

Откройте проект в Android Studio с JDK 17. CI workflow находится в `.github/workflows/android-debug-apk.yml` и запускается при push в `main` либо вручную из GitHub Actions. Он собирает debug APK и публикует его как артефакт `ApocalypseAssistant-debug-apk`.

## Следующие этапы

1. Добавить экран наблюдения через системное разрешение Android MediaProjection.
2. Реализовать OCR с оценкой уверенности и явным состоянием UNKNOWN.
3. Сверять валютные балансы до и после разрешённых действий; при любом уменьшении — аварийная остановка.
4. Добавлять автоматизацию только после проверки условий игры и только для однозначно бесплатных действий.
5. Проверить ограничения Android для фоновой работы; не обещать гарантированные 24/7 при выключенном экране.

Не обходить античит, защиту или правила игры.
